Derive analysis variables and apply the exclusion

This step derives the variables used in Table 1 and the models:

  • Immunosuppression. The free-text regimen in Drugs is upper-cased, then three indicators are set by searching it for character strings: calcineurin inhibitor (DrugCNI: PRO, T or CYC), mycophenolate (DrugMycophenolate: M or CELL) and mTOR inhibitor (DrugMTOR: SIR or EVER). Corticosteroid use comes directly from STEROID.
  • Serum cryptococcal antigen. SerumCrAg holds either a titer or the word “Negative”; CryptococcalAg stores the numeric titer, with negative results set to 0.
  • Site of infection. CNSDisease is true when the recorded infection site (InfSite) mentions CNS.
  • Exclusion. One participant recruited as a control is removed because their serum cryptococcal antigen was positive. This rule comes from the original analysis code, not the published methods. It leaves the final sample of 23 cases and 21 controls reported in the paper (Yoon et al. 2022).
  • Outcome. HasCryptococcus is the case/control status as a logical value, the outcome for the logistic regression models.
  • Transplanted organ is converted to title case so that differently capitalized entries are counted together.

#Data cleaning
CleanData<-RawData %>%
  #Create drug variables for CNI, mycophenolate, etc after cleaning up capitalization issues
  mutate(Drugs=toupper(Drugs)) %>%
  #DrugCNI variable is positive if drug regimen includes PRO (Prograf), T (tacrolimus), or CYC (cyclosporine)
  mutate(DrugCNI=grepl('PRO',Drugs)|grepl('T',Drugs)|grepl('CYC',Drugs)) %>%
  #DrugMycophenolate variable is positive if drug regimen includes M (mycophenolate) or CELL (Cellcept)
  mutate(DrugMycophenolate=grepl('M',Drugs)|grepl('CELL',Drugs)) %>%
  #DrugMTOR variable is positive if drug regimen includes SIR (sirolimus) or EVER (everolimus)
  mutate(DrugMTOR=grepl('SIR',Drugs)|grepl('EVER',Drugs)) %>%
  #Clean SerumCrAg variable and store numerical titer in CryptococcalAg variable
  mutate(CryptococcalAg=as.numeric(SerumCrAg)) %>%
  mutate(CryptococcalAg=ifelse(SerumCrAg %in% c("Negative", "negative"), 0, CryptococcalAg))%>%
  #Create variable for CNS disease
  mutate(CNSDisease=grepl('CNS',InfSite))%>%
  #Remove Subject 116-was control, but crypto antigen was positive
  filter(ID!=116)

#Create a binary HasCryptococcus variable for the purposes of logistic regression
CleanData<-CleanData %>% mutate(HasCryptococcus= CaseOrControl=="Case")

#We fix the capitalization issues in the TransplantOrgan variable
CleanData$TransplantOrgan<-str_to_title(CleanData$TransplantOrgan)

Log-transform the antibody levels

Antibody levels are strongly right-skewed, so a natural-log version of each is created (log_GXMIgM and so on). The regression models use both scales; the paper’s multivariable models and ROC curves use the log scale. The list of continuous variables (age, the seven antibodies and their logs) is defined here.

# Create logged versions of all titer variables
CleanData<-CleanData %>% mutate(across(TiterVariables, log, .names = "log_{col}"))

#Save the names of the logged titer variables into a list
LogTiterVariables<-paste0("log_",TiterVariables)

#Create a list of all continuous variables
