This script fits the logistic regression models relating cryptococcosis status to antibody levels, draws ROC curves for the multivariable models, and finds optimal titer cutpoints for GXM-IgM and Lam-IgM. Its tables and fitted objects are exported by Tables and Figures.

RcodeSource code

The full R script is available at:

  • R/modeling.R

This R script file is itself reliant on the following helper files:

  • R/setup.R
  • R/import_clean.R

The code sections below are imported directly from that script when this page is rendered.

The outcome throughout is HasCryptococcus (case versus control). Odds ratios are exponentiated logistic regression coefficients. All analyses were exploratory, with no correction for multiple comparisons (Yoon et al. 2022).

Univariable models on the original scale

tbl_uvregression() fits one logistic regression per candidate predictor: sex, race, corticosteroid, mycophenolate and mTOR inhibitor use, age, and the seven antibody levels on their original scale. Transplanted organ, calcineurin inhibitor use and CNS disease are left out. For context, CNS disease is recorded only for cases, and 43 of 44 participants received a calcineurin inhibitor (Yoon et al. 2022). An inline forest plot is added to each row.

univariatetitertable<-CleanData %>%

                   exponentiate = TRUE) %>%

ROC curves and AUC confidence intervals

ROC curves for models 1 and 2, as reported in the paper. Each AUC gets two 95% confidence intervals, computed with pROC (Robin et al. 2011): DeLong’s analytic method (DeLong et al. 1988) and a bootstrap. The bootstrap resamples at random, so its limits can differ slightly between runs.

Click to show/hide R Code 
#ROC curve 1
test_prob_logtiter1 = predict(mvlogtitermodel1, newdata = CleanData, type = "response")
logtiter_roc1 = pROC::roc(CleanData$HasCryptococcus ~ test_prob_logtiter1, plot = TRUE, print.auc = TRUE)

#Calculate 95% confidence intervals, both analytically and using bootstrapping
auc_ci_logtiter1_delong <- ci.auc(logtiter_roc1, method="delong")
auc_ci_logtiter1_bootstrap <- ci.auc(logtiter_roc1, method="bootstrap")

#ROC curve 2
test_prob_logtiter2 = predict(mvlogtitermodel2, newdata = CleanData, type = "response")
logtiter_roc2 = pROC::roc(CleanData$HasCryptococcus ~ test_prob_logtiter2, plot = TRUE, print.auc = TRUE)

#Calculate 95% confidence intervals, both analytically and using bootstrapping
auc_ci_logtiter2_delong <- ci.auc(logtiter_roc2, method="delong")
auc_ci_logtiter2_bootstrap <- ci.auc(logtiter_roc2, method="bootstrap")

Sensitivity analysis: one antibody at a time

GXM-IgM and Lam-IgM are strongly correlated, so with both in one model neither is individually significant. As a sensitivity analysis, each is modeled with sex alone (Yoon et al. 2022). These are the same specifications as models 3 and 4 above.

sensitivity_table_log_gxm_igm <- glm(HasCryptococcus ~ Sex+log_GXMIgM, family = binomial, data=CleanData) %>%

Optimal titer cutpoints

cutpointr() finds the GXM-IgM and Lam-IgM values, on both scales, that maximize the sum of sensitivity and specificity (the Youden index (Youden 1950)) (Thiele and Hirschfeld 2021), with case status as the positive class. add_metric() adds the positive and negative predictive values at that cutpoint. These cutpoints are estimated on the same data used to evaluate them, which tends to overstate their performance (Ewald 2006).

Click to show/hide R Code 
#Optimized cutpoints using sum of sensitivity and specificity
cutpoint_gxm_igm <- cutpointr(CleanData, GXMIgM, HasCryptococcus,
          method = maximize_metric, metric = sum_sens_spec, na.rm = TRUE, pos_class = "TRUE")%>%
  add_metric(list(ppv, npv))

cutpoint_log_gxm_igm <- cutpointr(CleanData, log_GXMIgM, HasCryptococcus,
          method = maximize_metric, metric = sum_sens_spec, na.rm = TRUE, pos_class = "TRUE")%>%
  add_metric(list(ppv, npv))

cutpoint_lam_igm <- cutpointr(CleanData, LAMIgM, HasCryptococcus,
          method = maximize_metric, metric = sum_sens_spec, na.rm = TRUE, pos_class = "TRUE")%>%
  add_metric(list(ppv, npv))

cutpoint_log_lam_igm <- cutpointr(CleanData, log_LAMIgM, HasCryptococcus,
          method = maximize_metric, metric = sum_sens_spec, na.rm = TRUE, pos_class = "TRUE")%>%
  add_metric(list(ppv, npv))
